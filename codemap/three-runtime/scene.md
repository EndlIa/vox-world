# src/three-runtime/scene.ts

Ring: 2 · Layer: three-runtime · Depends on: `../document/project.js`, `../voxels/uniform/grid.js`, `../voxels/octree/leafId.js`, `three`

## Responsibility
Mirrors the project into a `THREE.Scene`: exactly one `Object3D` per document object plus the output camera, and the derived `InstancedMesh` geometry that renders uniform cells and octree leaves. Owns every derived render resource and the instance-to-cell/leaf reverse maps. It owns no project data, no renderer, no DOM, and never the viewport camera. It also parents the app's imported raw meshes under their objects' nodes on layer 2 (README D24) — the raw half of the raw-versus-voxel comparison — places each one by its own baked node matrix (README D25), and never owns them: a source mesh, its geometry, and its material belong to the app and are never disposed by the mirror.

## Public interface
```ts
type CellLookup = { objectId: ObjectId; cells: [number, number, number][]; colors: HexColor[] };
type LeafLookupItem = { leafId: LeafId; depth: number; size: number; occupied: boolean; color: HexColor };
type LeafLookup = { objectId: ObjectId; leaves: LeafLookupItem[] };
class SceneMirror {
  constructor(project: Project, opts?: { background?: HexColor; ambientIntensity?: number });
  readonly scene: THREE.Scene;
  readonly camera: THREE.PerspectiveCamera;            // output camera, scene child named 'camera'
  sync(): void;                                        // rebuilds only objects marked dirty
  markDirty(id: ObjectId): void;
  objectOf(id: ObjectId): THREE.Object3D | undefined;
  lookupOf(id: ObjectId): CellLookup | LeafLookup | undefined;  // instanceId -> cell / leaf reverse map
  setMaskMode(enabled: boolean): void;                 // flat per-object maskColor materials
  attachSourceObject(id: ObjectId, source: THREE.Object3D, nodeWorldMatrix: THREE.Matrix4): void;  // raw mesh on layer 2, placed by its baked node matrix
  setSourceVisible(enabled: boolean): void;            // global raw-mesh override, applied at once
  get sourceVisible(): boolean;
  frameAll(camera: THREE.PerspectiveCamera): void;      // fits the given camera to layers 0 and 2
  dispose(): void;
}
```
`ObjectId`/`Project` come from `document/project.js`, `HexColor` from `voxels/uniform/grid.js`, `LeafId` from `voxels/octree/leafId.js`; none is re-declared here.

## Internal logic
1. Construction: `scene.background = new THREE.Color(background ?? project.settings.background)`, one `AmbientLight` at `ambientIntensity ?? project.settings.ambientIntensity`, one unconfigurable `DirectionalLight` so cube faces are distinguishable, and `camera = new THREE.PerspectiveCamera(project.camera.fov, 1, project.camera.near, project.camera.far)` with `camera.name = 'camera'` and its transform copied from `project.camera.transform`, added as a child of the scene root. That camera is the **output** camera: export, the aspect guide, and the `camera.fov` track use it and nothing else (README D17, D22). It is not the app's viewport camera; navigation moves the viewport camera, except while the camera lock is on, when the app retargets navigation to this camera (README D17). The mirror itself never moves either camera — it neither creates nor drives the viewport camera, and it never overwrites this one after construction, so the mixer and the composition root keep ownership.
2. `sync()` step 1 — reconcile membership: every `project.objects` entry without a node gets one (`Group` for `representation: 'empty'`; a single `InstancedMesh` for `uniform`; a `Group` holding one `InstancedMesh` per leaf-size bucket for `octree`), and every mirrored id that left the project has its node removed, its geometry/material/instance buffers disposed, and its lookup dropped.
3. `sync()` step 2 — hierarchy and transform: each node is added under its `parentId`'s node (or the scene root), `node.position/quaternion/scale` are copied from `object.transform`, and `node.visible = object.visible`. The hierarchy comes from `parentId`; nothing is ever read back out of an `Object3D`. The output camera node is created here from `project.camera` (name, transform, fov, near, far) and afterwards belongs to the mixer and the composition root, so `sync()` never overwrites it and cannot fight the timeline.
4. Naming (README D22): every mirrored object node gets `node.name = <ObjectId>` so one `AnimationMixer` rooted at `scene` can bind `obj-4.position`; the camera node is named `camera` for `camera.fov`. Each of those nodes also gets `userData.objectId = id`, and bucket meshes get `userData.instanceBase` and stay unnamed, so a track or a lookup can never resolve to an instance mesh. Renaming an object never touches `Object3D.name`; the display name lives only in the document.
5. `sync()` step 3 — rebuild dirty objects only (README D4): the ids marked by `markDirty`, plus objects created in step 1. No scheduler, no incremental update graph; a clean object keeps its node, mesh, instance buffers, and lookup identity.
6. Uniform rebuild: one `InstancedMesh` over a `BoxGeometry(voxelSize, voxelSize, voxelSize)` with `count = grid.size`; instance `i` gets `setMatrixAt(i, translation of the cell center)` and `setColorAt(i, color)` in `grid.forEach` order, and `CellLookup.cells[i]` / `.colors[i]` are filled from the same `UniformGrid` in that same order.
7. Octree rebuild: leaves are bucketed by depth, buckets are emitted deepest depth first, and inside a bucket leaf order is ascending `LeafId` string. Each bucket is one `InstancedMesh` sharing one `BoxGeometry(leafSize, leafSize, leafSize)` per depth and translating to the leaf center `(i + 0.5) * leafSize` derived from the leaf's path digits. Instance ordering is part of the pick contract: deeper leaf, then nearer distance, then ascending `LeafId`.
8. `LeafLookup.leaves[i] = { leafId, depth, size: octree.leafSize(depth), occupied, color }` is read from the `Octree` leaf attrs while instance `i` is written; `leaves` is the object-wide concatenation of the buckets in the same order, and each bucket records its own `userData.instanceBase` (its first instance's index in that array) — the reverse index `picking.ts` resolves `instanceId` through together with `userData.objectId`.
9. Both lookups are built from document data inside the rebuild that creates the instances, and are never derived from mesh, material, or instance-color state. A material swap, `setMaskMode(true)`, or the instance-color stash therefore cannot change what picking or the HUD reports. A lookup is replaced together with the instances it describes, never patched in place, so a stale `instanceId` cannot resolve to a wrong cell or leaf.
10. `setMaskMode(true)` swaps every voxel mesh to a fresh unlit `MeshBasicMaterial({ color: maskColor, toneMapped: false })` and clears `instanceColor` (stashing the attribute) so one render pass produces flat identity frames; `setMaskMode(false)` restores the shared shading material and the stashed colors. Repeated enables are idempotent and never overwrite the stash.
11. `frameAll(camera)` computes the union `Box3` of the mirrored nodes, measuring camera layers 0 and 2 and skipping layer 1 so viewport decorations never widen the frame, then fits the **given** camera to that box: position along the camera's current view direction at `radius / sin(fov/2) * 1.1` from the center, `lookAt` the center, `near`/`far` widened to contain the box, `updateProjectionMatrix()` called. `Box3.setFromObject(node, true)` already includes the node's source-mesh children, so an import frames the imported model before any payload exists; the output camera is never framed here, because it is a document node the user or the timeline owns.
12. `attachSourceObject(id, source, nodeWorldMatrix)` tags `source.userData.objectId = id`, puts it on layer 2 with `source.layers.set(2)` (so the viewport camera draws it, the raycaster can reach it, and the output camera — which tests layer 0 alone — cannot), and records it in the mirror's `sources` map under `id` together with a clone of `nodeWorldMatrix`, the imported mesh node's baked world matrix (README D25). The clone is deliberate: the caller's matrix belongs to the imported scene and stays live there. The same mesh attached twice stays one entry (`Array.includes`), so a repeated attach cannot duplicate a child; a second attach under the same id refreshes the recorded matrix. When the node already exists the meshes are parented at once; an id whose node does not exist yet — an import that attaches before the next `sync()` — is attached by the rebuild that creates it.
13. `sync()` step 4 walks every recorded id and applies the same rules the rest of `sync()` applies to derived nodes: parent each mesh under the object's current node when it is not already there (which is how a rebuilt node adopts the meshes of the node it replaced, without a second copy), place it, and set `source.visible = sourceVisible || object.representation === 'empty'`. The rule lives in `applySources`, the only place that writes a source mesh's parent, matrix, `matrixAutoUpdate`, `matrixWorldNeedsUpdate`, or `visible`; `sync()` runs it for every recorded id, and `attachSourceObject` and `setSourceVisible` run it as well.
14. The placement (README D25) is the mesh's local matrix, `project.worldMatrix(id)⁻¹ ∘ record.nodeMatrix`, computed into one scratch `Matrix4` per apply and copied onto every mesh of that id, with `matrixAutoUpdate = false` and `matrixWorldNeedsUpdate = true`. The mesh's own world matrix is then exactly the imported node's, whatever the document node has become: before voxelization the object's transform is that matrix, so the local result is the identity, and after `applyVoxelizeResult` made the object translation-only it is the `-origin` offset that keeps the raw mesh where the import put it. Writing it on every apply — including every frame's `sync()` — is what stops a mixer track, a rebuild, or a stale `matrixWorld` from drifting a raw mesh away from its import pose. (`worldMatrix` returns a fresh `Matrix4`, so the copy into the scratch is what keeps a per-id apply allocation-free.)
15. `setSourceVisible(enabled)` stores the global override and immediately re-applies it to every recorded source mesh, and `get sourceVisible()` reads the stored flag back. The application is not left to `sync()`: this is a live control, every object holds a payload after a voxelization so nothing is dirty, and a setter that only recorded the flag would show the old state until an unrelated rebuild happened to publish it. `sync()`'s pass stays as the second, redundant path that keeps a source attached or rebuilt later correct; a repeated call with the same value returns before touching a mesh. Nothing else about the rule changes: off, a raw mesh renders only while its object has no payload, so the first voxelization hides it and the raw-versus-voxel comparison needs the override, and a source mesh whose object is later deleted simply stops being reached, because its entry is gone.

## Invariants
- One `Object3D` per document object: after `sync()` the node set equals `project.objects`, every node is a descendant of `mirror.scene`, and the output camera is a child of the scene root named `camera` (D22), so one `AnimationMixer` rooted at `scene` reaches all of them.
- Exactly two cameras exist at runtime: `mirror.camera`, the output camera, and the app's viewport camera, which the mirror never creates, reads, or moves (README D17). `frameAll(camera)` frames only the camera it is given, so `mirror.camera` is never reframed by a view operation.
- `objectOf(id)` returns the mirrored node of a live object and `undefined` for anything else.
- `sync()` with no dirty marks rebuilds nothing: node, mesh, and lookup identities are unchanged. It does still re-derive every attached source mesh's local matrix and re-parent/visibility — that write is idempotent, touches no document data, and is what keeps the raw meshes correct without anyone having to mark them.
- `CellLookup.cells.length === CellLookup.colors.length === mesh.count`, and `LeafLookup.leaves.length` equals the sum of the bucket counts; index `i` of a lookup always describes instance `i` of that object, with `depth`, `size`, `occupied`, and `color` taken from the container.
- Instances exist only for occupied cells and occupied leaves, so occupancy is true for everything a ray can hit.
- In mask mode no mesh carries an `instanceColor`, so the mask color is the only color in the frame; silhouettes and both lookups are unchanged because geometry, instance matrices, and lookups do not depend on material or instance-color state.
- Viewport-only decorations (the box preview, the leaf-bounds wireframe, the aspect guide) live on camera layer 1; the raycaster tests layers 0 and 2 and the export camera tests layer 0 alone (README D24).
- A source mesh is a child of its object's mirrored node and of nothing else, appears exactly once under it, and tests layer 2 and no other layer; its `userData.objectId` is the id it was attached with, so `picking.ts` resolves it to that object.
- A source mesh's world matrix equals the imported node's baked world matrix it was attached with, within floating-point error, at every point in the object's life: while the object still carries that imported transform (the local placement is then the identity) and after `applyVoxelizeResult` made the object translation-only (the local placement is then the `-origin` offset). That is the whole point of the baked node matrix (README D25) — the raw-versus-voxel comparison stays glued to the import, so a mesh that looks misplaced is a placement bug, never an imported one.
- A source mesh renders exactly when `sourceVisible` is true **or** its object's `representation` is `'empty'`: the moment a voxelization attaches a payload the raw mesh hides unless the override is on, which is what keeps an exported frame free of duplicate geometry and makes the comparison a user choice.
- Every write the mirror makes to a source mesh is `parent`, `matrix`, `matrixAutoUpdate`, `matrixWorldNeedsUpdate`, and `visible`, and all happen only inside `applySources`, which `sync()` runs for every recorded id, and which `attachSourceObject` and `setSourceVisible` run too. The mirror never disposes a source mesh, its geometry, its material, or a descendant of it, and `dispose()` drops only the mirror's own records of them.
- The override lands on the next rendered frame with no `sync()` in between: `setSourceVisible` re-applies it to every recorded mesh the moment it stores the flag, so no caller has to mark anything dirty or wait for a rebuild. This is deliberate, and it is the class of mistake to avoid here — a setter that only records intent is wrong for a live control, because after a voxelization every object holds a payload and nothing is dirty, so nothing would ever publish the change. `sync()` re-applying the rule is a second, redundant path, not the path the toggle depends on.
- `setSourceVisible` with the value already stored returns before touching a mesh, so a repeated call is free.
- `sync()` is idempotent for source meshes: attaching the same mesh again, syncing twice, or rebuilding the object's node leaves exactly one child per attached mesh, with the same placement and the same visibility.
- `frameAll` measures exactly the nodes whose layers intersect `{0, 2}`; a layer-1 node is skipped, and a node's layer-2 children are measured with it.
- `dispose()` releases every geometry, material, instance buffer, and lookup the mirror created; it never disposes a voxel container, a document value, or an app-owned source mesh.

## Errors
- `markDirty(id)` with an id that is not in `project.objects` throws `TypeError` — a stale mark is a bug, and ignoring it silently would leave the mirror wrong.
- `lookupOf(id)` returns `undefined` for an unknown id, an `empty` object, and an object whose payload has no occupied content; it never returns a lookup whose instances do not exist.
- `attachSourceObject(id, source, nodeWorldMatrix)` is a request, not an assertion: an id the project does not hold yet (or no longer holds) is recorded and simply never reached by `sync()` until that object exists, so no error is raised and nothing is attached for it. A mesh already attached under the same id is kept as the single child it already is, and the recorded node matrix is refreshed. A caller that never attaches anything sees no source meshes at all — the layer is empty, not implied by the object. The matrix is cloned, so the caller may keep mutating the one it passed.
- `sync()`, `lookupOf`, `objectOf`, `attachSourceObject`, and `setSourceVisible` never throw for a structurally legal project.

## Dependencies
- `three` — `Scene`, `Object3D`, `Group`, `InstancedMesh`, `BoxGeometry`, `MeshBasicMaterial`, `MeshLambertMaterial`, `PerspectiveCamera`, `DirectionalLight`, `AmbientLight`, `Color`, `Box3`, `Vector3`, `Matrix4` (the source placement and the attachment contract), `Layers`.
- `../document/project.js` — `Project`, `ObjectId`, `SceneObject` (whose `representation` is the payload test of the source-mesh visibility rule).
- `../voxels/uniform/grid.js` — `HexColor` only.
- `../voxels/octree/leafId.js` — `LeafId`, `decodeLeafId` (instance translation and leaf ordering).
No outer-ring import: no editor, no UI, no capture. A source mesh arrives as an `Object3D` from the caller; the mirror never builds one.

## Tests
- `tests/scene.test.ts` (node environment, constructing `InstancedMesh` needs no renderer): one instance per occupied cell with `cells[i]` and `colors[i]` matching instance `i`; octree buckets split by depth, deepest bucket first, ascending `LeafId` inside a bucket, `instanceBase` matching the concatenated `leaves`, and each item's `depth`/`size`/`occupied`/`color` equal to the source leaf's attrs; lookup length equals `count`; `markDirty` + `sync` rebuilds only the marked object; a second `sync` is a no-op; mask mode leaves no `instanceColor`, restores the previous colors on exit, and leaves both lookups value-identical; `markDirty` on an unknown id throws `TypeError`.
- Material and lighting appearance, and the auto-framed view, are verified by running the app (README §10).
- The source-mesh layer is also checked node-side, where no renderer is needed (a throwaway `vitest` repro against a real `Project` and `SceneMirror`): a mesh attached before its node exists ends up on layer 2 as the object's only child under `userData.objectId`; attaching it twice leaves one child; a `uniform` payload hides it, `setSourceVisible(true)` shows it again, and a rebuild moves it onto the replacement node; `frameAll` moves a camera that saw nothing on layer 0 onto a layer-2 mesh alone. The placement contract is checked the same way against real imported content (79 rotated, non-uniformly scaled nodes of a Sketchfab GLB): every object `applyVoxelizeResult` fills comes out translation-only, and every attached mesh's world matrix still equals its imported node's, before the payload (local placement ≈ identity) and after it (local placement ≈ the `-origin` offset).
